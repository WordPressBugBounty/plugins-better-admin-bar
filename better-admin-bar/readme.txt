The WordPress admin bar reimagined. Replace it with a quick access panel, auto-hide it or hide it for specific user roles.

== Description ==

**[Better Admin Bar](https://betteradminbar.com/?utm_source=repository&utm_medium=link&utm_campaign=bab)** gives you and your clients a better way to get around WordPress. Replace the default admin bar with a clean **quick access panel** that floats on your website, or keep the admin bar and make it less in the way: **auto-hide it**, remove the 32px gap or **hide it for specific user roles**.

Set everything up under *Settings → Better Admin Bar*.

== Why choose Better Admin Bar? ==

= 🚀 Quick access panel =
A small floating button on your website. Click it and the key areas of your site are one click away: the dashboard, the customizer, a new page or post, and an "Edit" button for the page you're looking at. Drag it to any edge of the screen, it remembers where you left it.

= 🧩 Drag & drop widgets =
Choose the widgets of the panel with drag & drop, put them in any order, give them your own names and icons, and open them in a new tab if you like.

= 🎨 Your colors =
Change the colors of the panel and see the result right away in the live preview on the settings page.

= 👻 Auto-hide the admin bar =
The admin bar slides out of view and comes back when you move your mouse to the top of the screen. Set the delay and the animation speed.

= 👥 Hide the admin bar per user role =
Remove the admin bar for all users or only for subscribers, customers or any other user role.

= 🛠️ Admin bar fixes =
Remove the 32px gap the admin bar adds to your website, stop menu items from breaking into a second line, hide the admin bar on small screens and change its opacity.

= 📦 Export & import =
Move your settings to another website with a .json file.

== How to use ==

1. Go to *Settings → Better Admin Bar*.
2. **Quick Access Panel:** drag widgets from the sidebar into the panel and drop them in the order you like. Click *Edit* (or double-click a widget) to change its name and icon.
3. **Admin Bar:** remove the admin bar for some user roles, turn on auto-hide or remove the top gap.
4. Click *Save Changes*.

The quick access panel shows up on your website for editors and administrators.

== Installation ==
1. In your WordPress admin, go to *Plugins → Add New Plugin* and search for "Better Admin Bar".
2. Click *Install Now*, then *Activate*.
3. Go to *Settings → Better Admin Bar* to set up the quick access panel and the admin bar.

== Frequently Asked Questions ==

= Who sees the quick access panel? =
Logged-in editors and administrators, on the frontend of your website. Visitors never see it.

= How do I move the quick access panel? =
Drag the button to any edge of the screen. Its position is saved for each user.

= Can I use the quick access panel and keep the admin bar? =
Yes. The panel and the admin bar settings work independently. Remove the admin bar only if you want to.

= How do I hide the admin bar for everyone except administrators? =
Go to *Settings → Better Admin Bar → Admin Bar* and check every role except *Administrator* under *Remove it for*, then click *Save Changes*.

= Does it change the admin bar inside the WordPress dashboard? =
No. All settings apply to the frontend of your website only.

= Which icons can I use? =
Any of the 2,000+ [Lucide](https://lucide.dev) icons. Click *Edit* on a widget, then its icon, and search by name or topic. The icons are part of the page, nothing extra is loaded.

= Are my settings deleted when I delete the plugin? =
Only if you check *Remove all data when the plugin is deleted* under *Misc*. Deactivating the plugin always keeps them.
